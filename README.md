- AI-Assisted Feedback Tool for Programming Problems in DOMjudge

This project explores an AI-assisted feedback layer for programming problems in DOMjudge.

DOMjudge will handle submissions, compilation, testing and verdicts. The project will focus on generating useful feedback from the problem statement, submission verdict and, where available, a short student explanation.

- Planned feedback types

- Clarification-style questions about the problem
- Follow-up questions about reasoning, assumptions and complexity
- Verdict-aware feedback after submissions

- Initial scope

The project will use a small set of programming problems and focus on feedback quality, usefulness and avoiding solution leakage.

- Initial milestones

1. Investigate DOMjudge and how to access problem/submission information.
2. Define feedback types and safety rules.
3. Build a basic verdict-aware feedback prototype.
4. Add clarification and reasoning follow-up features.
5. Test on a small set of programming problems.
6. Evaluate the system and write up the results.
